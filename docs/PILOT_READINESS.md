# Pilot readiness and remaining work

This build is intended for local sandbox evaluation. A complete P0 release requires the following work to be verified in the actual staging environment.

1. Configure and exercise the dedicated Supabase project: registration/email confirmation, password recovery, session refresh/revocation, account linking, private bucket permissions, upload/read behavior across multiple API replicas, deletion/retention flows and production CORS/TLS.
2. Current user-directed QA scope is the connected **physical iPhone through iPhone Mirroring**; Android testing is deferred. Complete iPhone native acceptance first, then generate signed staging builds. A future cross-platform release still needs Android device QA. Native bundling and an earlier iOS Simulator walkthrough are separate evidence, not substitutes for device tests. Broaden native device coverage for rich-text/social-link editing, collection creation/editing/product ordering, collection filters, nested-column controls and crop behavior; finish continuous gesture DnD. Native layout uses platform typography and does not promise pixel-identical web rendering.
3. Full accessibility audit of buyer, editor, modal and checkout flows with keyboard/screen readers/large type. The automated Discover scan is limited to that route. Broaden per-theme contrast/heading guidance and test assistive technology throughout. Severe text/background contrast blocks publication; this is not full WCAG certification.
4. External moderation operations, restricted-goods review, block/mute, account deletion/retention and support escalation need completion before inviting public sellers. The internal report queue, audit trail and suspension endpoints exist; they do not provide staffed moderation.
5. Provider/legal review for Malaysian marketplace availability, merchant of record, seller onboarding/KYC, tax/e-invoicing, PDPA, refunds, disputes, consumer protection and terms. **Live payments and payouts remain disabled.**
6. Configure notification delivery, durable outbox/queue, telemetry/error capture with PII scrubbing, backups/restore drills, image retention/garbage collection, shared rate limiting across API workers and scheduled reservation expiry. The worker command is provided; no production scheduler was provisioned.
7. Exercise migration rollback/restore on staging and performance/load tests (Core Web Vitals, search latency, checkout contention). Current local checks are not field performance SLO measurements.
8. Broaden search to indexed full-text/trigram ranking and add public catalog pagination in the UI before a large catalog. The current deterministic search uses bounded SQL filters/ILIKE and a paginated API.
9. Replace fictional sample seller/product/policy/photo content with owned/approved pilot content. No sample reviews or verification marks imply real transaction history.
10. Deploy the required web/API/database stack, set canonical/asset URLs, health probes and secure environment secrets; verify cache behavior. Build and CI configuration is supplied; no remote CI or production deployment has run.
